# Reach

Audience: ETHGlobal attendees and interactive-event hosts who want a crowd to influence one visible venue mission. Potential integrators are small game/event developers interested in wallet-owned shared world structures.

Public website: https://rift-run-mumbai-2026.madhanxdev.chatgpt.site with /play and /crowd. Native Sites publication succeeded on 6 November 2026. Browser/phone gameplay and live Arkiv intervention proof remain unverified in the current evidence record.

## Can users try it today?

Local practice can be served with npm run dev. It has a checkpoint mission and same-browser shared simulated edits. Live participation requires a funded Rabdi wallet, registration before roster lock and a real host lobby. We have not yet recorded a successful funded end-to-end round.

## Measured reach

No measured unique human sessions, completed human rounds, retention metrics or consented testimonials are available. Unit tests use synthetic identities and are not participants. The UI labels roster registrations rather than pretending to measure online attendance. A 16-wallet capacity is a software bound, not measured turnout.

Wallet installation/funding and transaction prompts are real onboarding friction; the user explicitly chose direct-wallet participation. Test the actual QR and wallet-browser path with attendees before claiming usability. No server-side gas sponsorship is implemented.
